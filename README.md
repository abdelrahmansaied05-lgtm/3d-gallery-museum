# 🎨 معرض فني تفاعلي 3D - Interactive Art Gallery

تطبيق معرض فني تفاعلي بتقنية 3D يحاكي تجربة المشي الفعلي في معرض فني حقيقي.

## ✨ المميزات

- 🚶 **الحركة الحرة**: تمشي داخل ممر المعرض بشكل طبيعي
- 🖼️ **لوحات فنية**: صور معلقة على الجدران يمين وشمال
- 🔐 **باب محمي برقم سري**: الرقم **13102024**
- 🎉 **احتفالية عند الفتح**: موسيقى وتأثيرات جميلة عند فتح الباب
- 📸 **معرض الصور**: عرض جميع الصور خارج الممر
- 🕹️ **تحكم سهل**: فأرة + لوحة مفاتيح

## 🎮 طريقة التحكم

| الحركة | المفتاح |
|--------|--------|
| للأمام | W أو ↑ |
| للخلف | S أو ↓ |
| لليمين | D |
| لليسار | A |
| القفز | Space |
| الالتفات | حرك الفأرة |

## 🔒 الوصول إلى الباب

- توجه للأمام حتى تصل إلى نهاية الممر
- سيطلب منك الرمز السري
- أدخل: **13102024**
- سيتم فتح الباب مع احتفالية وموسيقى جميلة!

## 🛠️ التقنيات المستخدمة

- **Three.js** - محرك رسومات 3D
- **HTML5 Canvas** - رسم الرسومات
- **Web Audio API** - تشغيل الموسيقى
- **Pointer Lock API** - التحكم بالفأرة

## 🚀 الاستخدام

1. فتح الملف `index.html` في المتصفح
2. اضغط على الشاشة لتفعيل الفأرة
3. استخدم W/A/S/D أو الأسهم للحركة
4. توجه نحو الباب في نهاية الممر
5. أدخل الرمز السري: **13102024**
6. استمتع بالمعرض! 🎨
